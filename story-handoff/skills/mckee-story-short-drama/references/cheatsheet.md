# 决策规则速查 — 故事

| 能力 | 一句话规则 |
|---|---|
| 用预期与结果的鸿沟推动下一步 | 人物依其认知行动，现实的反应偏离预期，迫使他再选择。 |
| 让激励事件连接主角的追求 | 激励事件打破主角生活的平衡，引起回应和欲望对象。 |
| 用不可退回的后果推进纠葛 | 递进纠葛让旧办法失效，并推动人物承担更大的风险。 |
| 按五步分析场景转折 | 场景分析依次核对冲突、开场价值、行动反应节拍、结尾价值及转折点。 |
| 让结尾的危机形成真正两难 | 危机是终极决定，迫使人物面对不能兼得的价值或两种代价。 |
| 用高潮行动兑现结尾变化 | 高潮行动实现决定性价值变化，写作者可从结尾回查必要的铺垫。 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
