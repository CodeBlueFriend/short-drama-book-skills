# 决策规则速查 — 故事：材质、结构、风格和银幕剧作的原理

| 能力 | 一句话规则 |
|---|---|
| 用预期与结果的鸿沟推动下一步 | 修改一场行动戏时，分别写出主角的目标、他预期的反应和实际结果，再由结果确定下一步行动。实际结果与预期相同时，检查这场戏是否还承担了必要的关系变化。 |
| 让激励事件连接主角的追求 | 检查开篇时，写明事件改变主角的什么处境、主角何时得知，以及他因此想得到什么。需要先铺设再被主角发现的事件，要让这两步在因果上接通。 |
| 用进展纠葛推进连续剧情 | 审查连续事件时，为每次失败记录它取消了哪种旧办法、人物下一步必须承担什么新代价。若人物仍可原样重试，检查本次事件是否真正推进了纠葛。 |
| 按五步分析场景转折 | 按冲突、开场价值状态、行动反应节拍、结尾价值状态、转折点的顺序分析一场戏。用具体动作或事实证明变化，最后定位使结果改变的那个节拍。 |
| 让结尾的危机形成真正两难 | 设计终局决定时，把角色实际可选的两条路及各自代价写出来。若存在一条符合既定条件、能轻易保全两边的路，先处理这条路，再让人物作决定。 |
| 用高潮行动兑现结尾变化 | 确定结局后，写出造成最终变化的可见行动，再反查该行动所需的能力、信息和条件是否已建立。每处缺口都补到因果合适的早先场次。 |
| 选择全剧结构并对齐结局承诺 | 策划全季时先写清驱动者、主要因果、时间安排与结局开放程度，再检查分集安排是否兑现了这种讲述选择。 |
| 用背景约束筛查情节可能性 | 设计重大行动前，先核对时代、故事期限、地点和冲突层面的限制，再把所需专业事实列为已确认或待查。 |
| 按类型常规设计观众期待 | 确定题材后，先识别本项目承诺给观众的核心体验和必需场面，再设计保留、变化与混合的具体做法。 |
| 用压力下的选择建立人物性格 | 写主要人物时，为想表达的性格设计一个有真实代价的选择，并记录他在不同关系与压力中显露的矛盾。 |
| 从结局回查主控思想 | 结局确定后，用“什么价值变成怎样，因为何种行动或力量”写出主控思想，再回查故事是否让相反的力量获得充分表现。 |
| 让分晓能回溯到充分伏笔 | 对每个关键揭露，写出观众事后需要理解的因果，再检查前文是否已让相关线索可见并具有当时的合理用途。 |
| 按紧张与释放重排分集节奏 | 节奏拖沓时，分别检查场次长短、内部活动强度和主线压力，再决定删减、合并或调换。 |
| 让对抗触及核心价值的深层威胁 | 主线压力不足时，围绕最重要的价值列出不同层面的威胁，再选择会迫使主角改变行动的一种深化。 |
| 把解说放进眼前行动和冲突 | 场景只在交代背景时，逐条检查哪些事实是观众此刻必须知道的，再为保留的信息设计角色说出或展示它的当下理由。 |
| 用知情差选择神秘、悬念或戏剧反讽 | 设计一段追看动机时，先排清观众与主要人物各知道什么，再明确要让观众追问真相、担心未来，还是看人物走进已知危险。 |
| 把抽象心理改成可见可听的动作 | 改写场景说明时，为每个抽象心理判断指出画面或声音中的证据，再用具体的人物动作、物件和变化表达。 |
| 先验证事件再扩成场次与对白 | 开展一轮剧本写作时，先用步骤大纲检验事件与结尾，再扩展动作、潜文本和对白。发现结构缺口时回到相应的大纲或场次层修改。 |
| 把原作事件重建为可拍的改编大纲 | 改编小说为短剧时，先按故事内时间顺序提取事件，再围绕原作核心体验设计可拍的动作与场次，逐项记录删改及其影响。 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
